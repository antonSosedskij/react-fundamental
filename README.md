# Помодоро

Учебный проект для изучения React. План и спецификация: [docs/MVP.md](docs/MVP.md).

```bash
npm install
npm run dev          # дев-сервер
npm test             # тесты-спецификации (сейчас падают на "Not implemented" — так задумано)
npm run test:watch
npm run lint
npm run typecheck
npm run build
npm run format
```
